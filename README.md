# Ventana Secundaria desde un Botón en Java

## Descripción

Este proyecto consiste en desarrollar una aplicación en **Java** que incluye un botón en la ventana principal. Al pulsarlo, se abre una **ventana secundaria** que muestra un mensaje al usuario.

El objetivo del ejercicio es practicar la creación y gestión de múltiples ventanas utilizando interfaces gráficas con **Swing**, así como el manejo de eventos mediante botones.

## Objetivos

- Crear una ventana principal en Java.
- Implementar un botón con gestión de eventos.
- Abrir una segunda ventana al pulsar el botón.
- Mostrar un mensaje en la ventana secundaria.
- Trabajar con múltiples componentes gráficos.

## Funcionamiento

1. Se inicia la aplicación.
2. Aparece una ventana principal con un botón.
3. El usuario pulsa el botón.
4. Se abre una ventana secundaria.
5. La nueva ventana muestra un mensaje informativo.
